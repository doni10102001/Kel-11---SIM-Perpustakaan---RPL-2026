# Arsip Pengembangan

Folder ini menyimpan dokumen historis SIM Perpustakaan yang **tidak lagi menggambarkan kondisi aplikasi saat ini**. Dokumen dipertahankan sebagai jejak pengembangan dan bukti proses, bukan sebagai acuan status terkini.

Untuk status terkini, gunakan [paket Tugas 10](../TUGAS-10-FINAL/README.md) dan [dokumentasi teknis](../README.md#3-dokumentasi-teknis).

## Catatan

- Isi dokumen arsip **tidak diubah** saat dipindahkan (24 Nov 2026). Path di dalamnya, misalnya `docs/audit/…`, `docs/analysis/…`, atau `docs/screenshots/…`, mengikuti struktur folder pada saat dokumen itu ditulis.
- Screenshot prototipe adalah screenshot aplikasi, **bukan** ekspor Google Stitch. Penjelasannya ada di [nomor 7 paket Tugas 10](../TUGAS-10-FINAL/07-GOOGLE-STITCH/README.md).
- Checklist pengumpulan yang berlaku adalah [`TUGAS-10-FINAL/FINAL_SUBMISSION_CHECKLIST.md`](../TUGAS-10-FINAL/FINAL_SUBMISSION_CHECKLIST.md).
